MentHabit — Icon Generator

Genera los iconos PWA con la identidad MentHabit.
Descarga ambos PNGs y cópialos a public/icons/ reemplazando los existentes.

Paso 1: Haz clic en ambos botones para descargar los PNGs.
Paso 2: Copia los archivos descargados a public/icons/ reemplazando los existentes.
Paso 3: Ejecuta npm run build && npm run start para probar la PWA en producción.
